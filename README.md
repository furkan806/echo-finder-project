# Campus Connect Hub

Create a modern and beginner-friendly Campus Lost & Found System website for a BCA 1st semester college project.

Website Name

Campus Lost & Found

Main Goal

The website should help college students report lost items, report found items, search for items, and connect with the person who lost or found an item.

Pages & Features

1. Home Page

- Campus Lost & Found logo/name

- Short tagline: “Lost Something? Find It Here.”

- Buttons:

  - Report Lost Item

  - Report Found Item

  - Search Items

- Show recently reported lost/found items.

2. Report Lost Item

   Create a form with:

- Item name

- Category

- Description

- Lost date

- Lost location

- Item photo upload

- Student name

- Contact information

- Submit button

3. Report Found Item

   Create a similar form with:

- Item name

- Category

- Description

- Found date

- Found location

- Item photo upload

- Finder name

- Contact information

- Submit button

4. Search Items

   Allow users to search and filter items by:

- Item name

- Category

- Location

- Date

- Lost/Found status

5. Items Page

   Display items as attractive cards showing:

- Photo

- Item name

- Category

- Location

- Date

- Lost or Found status

- View Details button

6. Item Details

   Show complete item information and provide a Claim Item / Contact button.

7. Login & Registration

   Create simple student registration and login pages.

8. Admin Dashboard

   Admin should be able to:

- View reported items

- Approve or reject reports

- Delete inappropriate reports

- Mark items as Returned

- Manage users

9. Contact/Help Page

   Add basic college help-desk information and instructions for returning found items.

Design

- Clean and professional college-project design

- Responsive for mobile, tablet and desktop

- Easy navigation

- Modern cards and buttons

- Use a simple blue/white theme

- Add icons where appropriate

- Make the interface beginner-friendly

Important

Make the website fully functional, not just a static design. Use sample data so the website looks populated when opened. Add proper validation to forms and show success/error messages after submissions.
